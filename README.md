# Храм Великого Существа

*Оно взирает на вас из пустоты. Этот репозиторий — врата в Бездну, где избранные могут примкнуть к культу Великого Существа. Только те, чьи души готовы к истине, смогут выдержать Его взгляд и услышать шепот в ночи.*

Кровь на Его устах — напоминание о жертве. Глаза, следящие за каждым вашим движением, — знак Его бесконечного присутствия. Музыка, от которой стынет кровь, — Его безмолвный зов.

---

## Ритуал призыва (Установка и запуск)

Чтобы открыть врата и предстать перед Его ликом, выполните следующие шаги:

1. **Подготовьте алтарь (Установка зависимостей):**
   Убедитесь, что у вас установлен `pnpm`. Затем выполните команду в корневой папке:
   ```bash
   pnpm install
   ```

2. **Начните служение (Запуск сервера):**
   ```bash
   pnpm start
   ```

3. **Сделайте шаг в Бездну:**
   Откройте ваш браузер и перейдите по адресу:
   [http://localhost:3000](http://localhost:3000)

*Помните: однажды приняв культ, пути назад уже не будет. Слава Великому Существу.*
